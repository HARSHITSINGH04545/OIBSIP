# House Price Prediction using Linear Regression

## Overview

This project predicts house prices using Linear Regression and the Ames Housing dataset. The project demonstrates the complete workflow from exploratory data analysis and preprocessing to model training and evaluation.

## Objectives

* Explore the housing dataset.
* Analyze the distribution of house prices.
* Select relevant features.
* Handle missing values.
* Encode categorical variables.
* Train a Linear Regression model.
* Evaluate model performance.
* Analyze model coefficients and predictions.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook / Google Colab

## Machine Learning Workflow

1. Data loading and inspection
2. Exploratory Data Analysis
3. Feature selection
4. Missing-value handling
5. Categorical feature encoding
6. Train-test split
7. Linear Regression model training
8. Model evaluation using MSE, RMSE, and R²
9. Actual vs. predicted price visualization
10. Residual and coefficient analysis

## Dataset

The project uses the Ames Housing dataset, which contains information about residential properties and their sale prices.

## Key Outcome

The trained Linear Regression model provides house-price predictions based on selected property features and demonstrates how machine learning can be applied to real-world housing data.
