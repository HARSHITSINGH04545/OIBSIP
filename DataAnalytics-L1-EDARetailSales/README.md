# Retail Sales Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer demographics, and product/category performance.

## Objectives

* Understand the structure and characteristics of the retail sales data.
* Analyze sales trends over time.
* Study customer demographics.
* Analyze product/category performance.
* Identify relationships between numerical variables.
* Generate business insights and recommendations.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## Analysis Performed

* Data loading and inspection
* Descriptive statistics
* Missing-value and duplicate checks
* Time-series analysis
* Customer demographic analysis
* Product/category analysis
* Correlation analysis
* Data visualization
* Business recommendations

## Key Outcome

The analysis helps identify important sales patterns, customer characteristics, and category-level performance that can support data-driven business decisions.
